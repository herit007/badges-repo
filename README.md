# 🏆 GitHub Achievements Hub

Welcome to the **GitHub Achievements Hub**! This repository is designed to be a comprehensive resource for developers looking to showcase their contributions and earn badges on their GitHub profile.

Whether you're aiming for the elusive **Galaxy Brain** or the popular **Starstruck** badge, this hub provides the scripts and guides you need to reach your goals.

## 🚀 Featured Badges
This repository specifically focuses on:
- **Starstruck**: How to build projects that people love and star.
- **Galaxy Brain**: Tips for contributing to Discussions and getting accepted answers.
- **Heart On Your Sleeve**: Encouraging community engagement and appreciation.
- **Open Sourcerer**: A roadmap for contributing to various open-source projects.

## 🛠 Tools Included

### `badge_info.py`
A CLI tool to quickly look up requirements and tips for various GitHub achievements.

**Usage:**
```bash
# List all supported badges
python badge_info.py --list

# Get details for a specific badge
python badge_info.py starstruck
```
